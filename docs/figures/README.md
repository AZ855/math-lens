# Public overview figure

`math-lens-overview.png` (1904×562, RGB) is an unchanged copy of a reviewed
portfolio composition. Its three panels are genuine application captures,
not synthesized mathematical output. It uses the public demonstration input
`assets/inputs/portfolio/architecture_geometric_facade_4x3.png`, which was
AI-generated as a demonstration input for Math Lens. The Voronoi and
Triangulation result panels were computed by the application, not AI-generated.

Left: original input. Center: Voronoi Balanced, controls 0.50 / 0.55 / 0.75,
Mean Region Color. Right: Colored Triangulation Balanced, controls
0.50 / 0.50 / 0.80 / 0.70, Mean Vertex, mesh edges shown. Pattern seed: 10.
Each captured result is a 600×450 panel. The two lenses do not share an
identical sampled site set; this is not an exact dual-geometry comparison.

The presentation adds headings and spacing without altering image colors,
geometry, or reveal masks. A large figure export does not imply additional
numerical resolution. Raw captures, videos, and internal capture manifests
are deliberately excluded from the public repository.

Input provenance and publication/licensing review are discussed in
[ATTRIBUTION.md](../../ATTRIBUTION.md).
